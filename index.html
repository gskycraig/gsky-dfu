讀取線上韌體清單中…
  1. 連接裝置：選「Mouse」（USB 線）或「Dongle」
  2. 確認目前的版本
  3. 網頁自動下載這個裝置的最新韌體
  4. 按「開始更新」，確認版本後開始傳送
  5. 裝置重新開機、換上新韌體，網頁自動檢查版本
注意
  • 更新時不要拔線、不要關掉這個網頁；先關掉 ap_web、dfu_gui 等同時連著裝置的工具。
  • 網頁依裝置的產品名稱（GM851 Mouse、Ex02 Mouse、GM855 Mouse、F03 Mouse、K+M Mouse 和各自的 Dongle）只給同一機種的韌體。Ex02 在 0.95 以前、GM855GT 在 0.8 以前、K+M（8M1K）在 0.99 以前的韌體還叫「GM851」，這些板子第一次換到新名稱要用 SWD 或 dfu_hid_update.py … --any-model。
  • 線上韌體放在這個網頁旁邊的 firmware/（清單 manifest.json，用 tools/make_dfu_site.py 產生）；直接開本機的 .html 讀不到，只能改用電腦裡的檔案。
  • 滑鼠更新完會自動確認新版本；新版開不了機時，下次重開會自動退回舊版。
  • dongle 沒有「退回上一版」，也不回報映像大小，只檢查版本號。
  • Do not unplug the cable or close this page during an update; first close ap_web, dfu_gui and any other tool connected to the device.
  • The page only offers firmware of the same model, by the device's product name (GM851 Mouse, Ex02 Mouse, GM855 Mouse, F03 Mouse, K+M Mouse and their dongles). Ex02 before 0.95, GM855GT before 0.8 and K+M (8M1K) before 0.99 still call themselves “GM851”; the first update of those boards to the new name needs SWD or dfu_hid_update.py … --any-model.
  • Online firmware sits next to this page in firmware/ (list manifest.json, made by tools/make_dfu_site.py); a page opened as a local .html file cannot read it, so use a file on this PC.
  • The mouse confirms the new version by itself after an update; if the new one cannot boot, the next restart goes back to the old one.
  • The dongle has no “Roll back” and does not report its image size; only the version number is checked.

測試模式 未進入

MP 測試中滑鼠不會睡眠。做過 RF 測試後「離開」會讓滑鼠重開機（射頻要重開機才回到 2.4G）。連 dongle 時指令轉給滑鼠。

滑鼠燈號

Dongle 燈號 只限連 dongle

60 秒或電腦睡眠時自動結束，恢復一般燈號。板子沒有某顆燈時會被拒絕。

按鍵測試

DPI 鍵：等待 按下 0 次

按滑鼠的 DPI 鍵，滑鼠會主動回報按下／放開（AD 04）。

RF 測試 只限有線

頻道：BLE 0～39 = 2402 + 2n MHz，2.4G 0～38 = 2403 + 2n MHz。網頁顯示「已送出」不代表滑鼠接受了，按「讀收包數」看「測試進行中」確認。

產品資訊

先讀再寫。寫入只儲存，不會改 USB 名稱。

配對碼

配對碼要分別寫進滑鼠（有線）和 dongle 兩邊，兩邊相同才連得上；或連 dongle 開配對視窗，再在滑鼠上按配對組合鍵。

重設

全部擦除會清掉設定、巨集、配對、產品資訊，滑鼠重開機。
