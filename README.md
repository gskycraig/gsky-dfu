# GSKY DFU

GSKY 滑鼠與接收器的韌體更新網頁（WebHID）。
Firmware update page for GSKY mice and dongles (WebHID).

**https://gskycraig.github.io/gsky-dfu/**

- 用電腦版 Chrome 或 Edge 開啟；滑鼠用 USB 線連接，接收器直接插上。
  Open it in Chrome or Edge on a computer; connect the mouse with its USB cable, plug the dongle in.
- 網頁會依裝置的產品名稱，自動選 `firmware/` 裡同一機種的最新韌體。
  The page picks the newest firmware of the same model from `firmware/`, by the device's product name.
- 右上角「⚙ 設定」可切換風格與語言（中文／English）。
  "⚙ Settings" (top right) switches the theme and the language.
